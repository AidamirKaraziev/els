# Передача: падения APK уходят в Sentry `rr-oe/els-app` с версией сборки

## Сделано и проверено

- `frontend/lib/helper/crash_reporting.dart`: `CrashReporting.run()` —
  `SentryFlutter.init` только при `--dart-define=SENTRY_DSN`, `release =
  els@<versionName>+<versionCode>`, трассировка выключена; `report()` для
  пойманных ошибок. `main.dart` запускает приложение через него.
- CI `.github/workflows/frontend.yml`: `SENTRY_DSN` из секрета в `build apk`;
  `apk info` печатает «Sentry: включён» / предупреждение. Секрет
  `SENTRY_DSN` в репо поставлен 2026-09-17 (`gh secret list`).
- Sentry: организация `rr-oe`, проект `els-app` (id 4512103307280464,
  платформа Flutter). Три события с dev-точки `lib/dev/crash_preview.dart`
  (обработчик, build, ручной `report`) видны в Issues с `release
  els@0.0.0-dev+1`.
- `sentry_flutter` 9.30.0, `intl` в lock не сдвинулся; APK с Sentry
  собран локально (78 МБ); `flutter build web` проходит.
- `docs/server-deploy.md` §3.5 «Крэш-репорты APK (Sentry)».
- `pubspec.yaml` → `1.0.4+5`. Коммит `d92ba47`.
- `make lint` чист, `make test` 1076, `flutter test test/mechanic` 158.
