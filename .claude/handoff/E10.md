# Передача: телефон получает push со звуком, иконкой и цветом по виду заявки; полный путь с сайта ждёт выкатки прода

## Сделано и проверено

- На Xiaomi (MIUI 816, Android 15) локальный APK: 19 проверочных push
  (`uv run python -m src.services.push --token … --look …`) пришли со звуком —
  в открытое, в закрытое и на заблокированный экран. Канал `emergency`,
  importance 5, вибрация — подтверждено `adb shell dumpsys notification`.
- Вид уведомления: `LOOKS` в `backend/src/services/push.py` —
  `alarm` красный/молния (категория `counts_as_breakdown` или без категории),
  `maintenance` зелёный/ключ (код ТО, ПТО), `request` синий/список
  (остальные), `removed` серый/крестик (снятие и передача, любая категория).
  Иконка и цвет уходят в `android.notification` (закрытое — рисует система),
  `data.look` — в открытом рисует `push_service.dart` через те же 4 drawable
  `frontend/android/app/src/main/res/drawable/ic_push_*.xml`; `res/raw/keep.xml`
  бережёт их от сжатия ресурсов. Все 4 вида видны на телефоне обоими путями.
- Проверки: `make lint` чист; бэк 1076 зелёных (push — 18, в т.ч. 3 вида по
  категории и «без категории — авария»); `flutter test test/mechanic` 139;
  `dart analyze push_service.dart` чист; `flutter build apk --release` собрался.

## Не доделано

- **Полный путь с сайта не проверен: на проде `els23.ru` нет S03.** В OpenAPI
  прода 190 путей и ни одного `/device-token/`; назначение с сайта push не
  даёт. Это критерий S06 («прод на main с S03, CI-APK прошёл S04 руками»).
- Снятие токена при выходе (`DELETE /device-token/`) — тоже проверяется
  только на проде после выкатки: лога прода локально нет.
- На телефоне стоит APK с debug-подписью (`ru.els23.app`, версия 1.0.1).
  CI-APK поверх не встанет — перед S06 удалить руками. `adb` — в
  `/opt/homebrew/share/android-commandlinetools/platform-tools/`; MIUI
  режет `adb install` без Mi-аккаунта → APK класть в `Download/` и ставить с телефона.
