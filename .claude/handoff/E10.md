# Передача: E10 закрыт — прод на main, APK 1.0.5 у механика, аудит без открытых расхождений

## Сделано и проверено

- Прод на `0df21f8` (S07–S09 + правка S11): `make prod-deploy` пройден
  пользователем 2026-09-18, сайт 200, в OpenAPI `/app/release`,
  `/app/download`, `/device-token/`.
- APK 1.0.4+5, затем 1.0.5+6 выложены через `scripts/publish-apk.sh` —
  https://els23.ru/app раздаёт `els-1.0.5.apk` (sha256 `e6eefbff…`).
- Аудит APK ↔ сайт на телефоне (логин, лента, шаги акта с фото, дефект,
  закрытие акта, офлайн-очередь): одно расхождение — без сети перезапуск
  показывал экран входа. Починено в `008f25c`: `Api.restoreSession()`
  держит пару при отказе сети, профиль `/auth/me` кешируется на диске
  (`profile_cache`), `AppRouter.restore()` берёт его офлайн. Форма входа
  помнит почту (`last_login_email`), пароль — нет. Проверено на телефоне
  с 1.0.5: авиарежим → перезапуск → лента на месте; выход → почта в поле.
- S10 «подпись заказчика» снят из плана — заказчику не нужна.
- `make lint` чист, `make test` 1076, `flutter test test/mechanic` 158,
  `flutter build web` ок. Заметка: `els-vault/knowledge/debugging/без сети
  приложение открывало экран входа при живом refresh-токене.md`.
