# Передача: в шапке механика — «Офлайн · ждут отправки: N» и плашка обновления

## Сделано и проверено

- `frontend/lib/mechanic/status_strip.dart`: `MechanicStatusStrip` (текст —
  `statusStripText()`) и `MechanicUpdateBanner`; старая `_StatusStrip` из
  `mechanic_shell.dart` удалена. Состояния: офлайн с очередью/без (жёлтая),
  «Отправляем: N» (зелёная), «Отклонено сервером: M» (красный значок),
  ошибка сервера текстом. Плашка «Вышла версия X · Обновить ✕» над полосой.
- `SyncResult.offline` (исключение в `Api.get`) → `WorkspaceStatus.offline`;
  `lastError` при офлайне не показывается. `checkForUpdate()` один раз в
  `start()`, только при `installedVersionCode > 0`; `dismissUpdate()` — до
  следующего запуска.
- Вживую на локальном стеке (`app-live-apk`, `APP_VERSION_CODE=3`, фикстура
  `release.json` 9.9.9): плашка → «Обновить» → экран «Приложение»; бэкенд
  погашен → «Офлайн · всё отправлено»; «Принять заявку» без сети → «ждут
  отправки: 1 · Открыть»; бэкенд поднят → очередь ушла, полосы нет.
- `test/mechanic/status_strip_test.dart` 8 тестов, всего по механику 158;
  `dart analyze lib/mechanic` без новых замечаний; `make lint`, `make test` 1076.
- `pubspec.yaml` → `1.0.3+4`. Набросок: `lib/dev/mechanic_strip_preview.dart`
  (`mechanic-strip-preview`, порт 5617) — утверждён 2026-09-17.

## Не доделано

- На телефоне не проверено: нужен CI-APK с main → `make apk-publish
  ARGS='--notes "Индикатор сети и плашка обновления в шапке"'` после влития;
  на Xiaomi с 1.0.2 должна появиться плашка «Вышла версия 1.0.3».
- Без сети приложение не проходит splash: `RootGate` ждёт `auth/me`. Офлайн
  работает только для уже открытого приложения. Вне S08; кандидат в план
  (E10 или отдельно): пускать по сохранённому профилю, если токен есть.
- Тестов на `SyncResult.offline`/`checkForUpdate` нет: `MechanicSync` и
  `AppReleaseApi` в тестах не подменяются. Проверено руками (см. выше).

## Первые шаги

1. В `frontend/pubspec.yaml` нет `sentry_flutter`, в `lib/main.dart` нет
   `runZonedGuarded`/`FlutterError.onError` — начинать с нуля. `flutter pub
   get` локально не гонять без нужды (CLAUDE.md: `intl` расходится с CI) —
   версию пакета подобрать по `pubspec.lock` Dart 3.10.
2. DSN — `--dart-define=SENTRY_DSN` в шаге `build apk` `.github/workflows/frontend.yml`
   рядом с `APP_VERSION_NAME/CODE`; `release` = `els@1.0.3+4` из тех же значений.
   Веб-сборка DSN не получает — там Sentry не нужен.
3. Проверка: кнопка «уронить» только в dev-точке (`lib/dev/`), не в APK;
   падение → событие в Sentry с `release`.
