# Передача: очередь видна на экране, снимки лежат на диске; всё это ждёт выкатки прода

## Сделано и проверено

- Экран `frontend/lib/mechanic/screens/outbox_screen.dart`: подпись «N ждут ·
  связи нет с HH:MM», кнопка «Отправить всё» (= `workspace.refresh()`),
  группы «Ждут отправки» и «Отклонено сервером»; у отклонённых «Повторить»
  (`Outbox.retryRejected`) и «Убрать» (`Outbox.dismissRejected`). Превью
  снимка 48 px из `Outbox.attachment`. Входы: тап по полосе состояния
  (`mechanic_shell.dart`, подпись «Открыть») и строка «Очередь отправки · N»
  в кабинете (`profile_screen.dart`, группа «Приложение»).
- Байты снимков — `BlobStore` (`local_store.dart`): на телефоне
  `DiskBlobStore` (`disk_blob_store.dart`, `getApplicationSupportDirectory()/outbox/`),
  в вебе `PreferencesBlobStore` (base64, как раньше), в тестах
  `MemoryBlobStore`. Старый base64-ключ в настройках дочитывается и
  удаляется после отправки — снимок прежней сборки не теряется.
- Отклонённое хранит снимок до «Убрать»/«Повторить»; `forgetRejected()` и
  `forget()` чистят диск. Причина отказа теперь копируется в запись
  отклонённого (раньше терялась при перечитывании очереди).
- `path_provider: any` в `pubspec.yaml`, в `pubspec.lock` `transitive → "direct
  main"` руками; `pub get` не запускался, `intl` на месте.
- Сжатие уже есть: `helper/image_picking.dart:pickWorkPhoto` (1600 px, 70).
- Проверки: `flutter test test/mechanic` — 150 зелёных (+7 в `outbox_test.dart`,
  +4 `outbox_screen_test.dart`); `dart analyze lib/mechanic test/mechanic` —
  только старые `withOpacity`; `flutter build web --release` и
  `flutter build apk --release` собрались; `make lint` чист, `make test`
  1076 зелёных.
- Руками на Xiaomi (локальный APK, `Download/els-s05.apk`): режим полёта →
  «в работу» + фото → полоса «Открыть» → карточки с превью и «ждёт» →
  «Отправить всё» без сети → сеть → список пуст, фото на сайте. Прошло.
