# Передача: бэк шаблонов готов — шаги списком, вид у модели удаляется мягко; дальше фронт S04 на живом API

## Сделано и проверено

- Ручки шаблонов (`backend/src/api/api_v1/endpoints/act_base.py`), старые пути живы:
  - `GET /acts-bases/?factory_model_id=N&include_deleted=false` — без фильтра как раньше (пагинация).
  - `GET /acts-bases/by-model/{factory_model_id}/` — все виды ТО модели по порядку видов,
    включая убранные: `{type_act{id,name}, template_id, steps[], steps_count, has_template, deleted_at}`.
    Модели нет → 404.
  - `POST /act-base/`, `PUT /act-base/{id}/` — принимают `steps: list[str]`; `step_list` строкой
    принимается, помечен deprecated. PUT частичный: не переданное не меняется.
    Дубль пары модель+вид → 403 код 1211 (как было), удалённая пара → 409 код 1212 «верните через restore».
  - `DELETE /act-base/{id}/?force=false` — мягкое (`deleted_at`); по шаблону стоят не начатые акты
    (status 1, is_actual) → 409 код 1213 «стоят N ТО», `force=true` удаляет всё равно; повтор — 200.
  - `POST /act-base/{id}/restore/` — снимает `deleted_at`. DELETE и restore — право `DIRECTORY_WRITE` (админ, прораб).
- Канон шаблона — та же форма, что у акта (`{"title":null,"steps":[{"id","title","done","comment"}]}`),
  хелперы `template_from_steps` / `template_steps` в `backend/src/services/checklist.py`;
  `parse_checklist` и `create_year_schedule` не трогались.
- `ActBaseGet` расширен: `steps`, `steps_count` (на лету), `deleted_at`. Старые поля на месте.
- Миграция `c3f8a1d27b64` — `acts_bases.deleted_at`. Удалённые исключены из
  `act_bases_by_type_act` (мастер графика) и `available_type_act_ids` (программа ТО);
  статистика считает шаги и в канонической форме (`crud_statistics._checklist_steps`).
- Тесты: `backend/tests/test_api_act_bases.py` (13), роль DELETE в матрице, снимок OpenAPI +18 строк.
  `make lint` зелёный, `make test` — 1115 passed. Руками на `make up` не проверялось — фронт зовёт в S04.
