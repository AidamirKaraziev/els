# Передача: «Шаблоны ТО» живут на acts-bases, «Добавить вид ТО» уже настоящий; дальше S05 — «Создать шаблон» в мастере

## Сделано и проверено

- `ApiTemplatesRepository` — `frontend/lib/screns/schedule/templates/repository/api_templates_repository.dart`:
  `loadAll` = `GET /all-factory-model/` (по страницам) × `GET /acts-bases/by-model/{id}/`;
  `save` = `PUT /act-base/{row}/` если строка пары есть (и с пустыми шагами тоже), иначе `POST /act-base/`;
  `addTypeAct` = `GET /type-acts/` → имя уже есть — берём id, нет — `POST /type-acts/`; потом `POST /act-base/ {steps: []}`;
  `removeTypeAct(force:)` = `DELETE /act-base/{row}/?force=`, на 409/1213 бросает `TemplateInUseException`;
  `restoreTypeAct` = `POST …/restore/`; `sources()` — из кэша последней загрузки.
  Id строк `acts_bases` репозиторий держит сам (`_rows` по паре модель × вид):
  `TemplateTypeAct.templateId` у экрана заполнен только когда шаги есть.
- Экран: ошибка любого действия — плашка с текстом сервера, список не перечитывается;
  409 «стоят N ТО» → диалог «Оставить / Удалить всё равно» → повтор с `force`;
  «Повторить» при неудачной загрузке; «видов ТО нет» у модели без видов.
- Кнопка «Шаблоны ТО» в сборке: `home_page.dart` и `home_foreman.dart` передают
  `ApiTemplatesRepository()` в `ScheduleSection` — по одной строке, больше оболочку не трогали.
- Проверено глазами на `make up` (образы пересобраны, миграция `c3f8a1d27b64` на head) под админом:
  вид «ТО 4» заведён у OTIS 14-432 RKS, шаблон скопирован из чужого и сохранён (`PUT /act-base/287/`),
  удалён и возвращён; на ТО 1 fssfds сервер ответил 409 «стоят 16 ТО» → вопрос → `?force=true` → 200,
  возвращено обратно. При выключенном бэке — 502; плашку доказывает виджет-тест (скриншот инструмента 4-секундную плашку не ловит).
- Тесты: `test/schedule/api_templates_repository_test.dart` (10), `templates_screen_errors_test.dart` (3),
  `new_type_act_dialog_test.dart` (Return = «Добавить»). `flutter test test/schedule` — 173 passed,
  `dart analyze` по затронутому чисто, `make lint` зелёный. `make test` (бэк) не гонялся — бэк не трогали.

## Первые шаги

1. Первая половина критерия уже сделана в S04 на экране шаблонов — в мастере осталось найти
   «не в справочнике»: `grep -rn "не в справочнике" frontend/lib/screns/schedule/object/wizard/`
   и ту же логику посадить на `ApiTemplatesRepository.addTypeAct` или прямой `POST /type-acts/`.
2. «Создать шаблон» в предпросмотре мастера: `showTemplateEditorDialog` из
   `templates/widgets/template_editor_dialog.dart` принимает `repository`, `model`, `typeAct`;
   после сохранения — `repository.save(...)` и перезапрос предпросмотра (`GET /planned-to/preview/`).
3. Сценарий целиком на `make up`: новый вид → программа модели → шаблон → график; акт механика
   с этими шагами — уже критерий S06.
