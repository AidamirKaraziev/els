# Передача: окно участков убрано, раздел по-прежнему живым никто не видел

**Ничего не закоммичено**: HEAD всё тот же `7f522b0`, работа двух сессий
целиком в рабочей копии.

## Сделано и проверено

- **Вход в «Графики» у админа — сразу лента всех объектов.** Промежуточное
  окно участков удалено целиком: экран, блок, тайл, модель, тест. У прораба
  вход не менялся. Развилки по роли в `ScheduleSection` больше нет.
- **`GET /schedules/divisions` удалена** — с `crud_schedules.divisions` и её
  помощниками, `get_schedule_divisions`, схемой `ScheduleDivisionRow`. В `main`
  ручки не было, прод не задет. `openapi_surface.json` пересобран.
- **Новый фильтр ленты `without_division=true`** — объекты без проставленного
  участка. Условие в `_object_conditions`, поэтому режет и строки, и клетки.
- **Разрез по участкам переехал на главную.** Строки карточки «Выполнение
  графика» кликабельны: уводят в «Графики» с фильтром участка и годом
  выбранного месяца, «Без участка» ставит новый фильтр. Переход — через
  `openSchedules()` в `frontend/lib/helper/app_section.dart`, заявка идёт
  через `ScheduleSectionRequest` и забирается ровно один раз.
- **Починен баг пилюли фильтра**: `_FilterPill` искала значение по `id`, а в
  `DropdownButton` отдавала пришедший объект — участок с тем же id, но другим
  названием (случай перехода с главной) ронял экран. Поймано тестом.
- **Проверки**: `make lint` чистый, `make test` — **836 тестов, все проходят**;
  `flutter test` — **310, все проходят**, `flutter analyze` по тронутому коду
  чист. Flutter: `~/development/flutter/bin`.

## Не доделано

- **Раздел не проверен руками ни разу.** Блок «Проверка / Фронт — `make up`»
  плана (строка 261 и дальше) не пройден ни в одном пункте — ни за прошлую
  сессию, ни за эту. Это и есть приёмка.
- **Пилюля «Участок» теперь никогда не пуста**: до прихода справочника в ней
  доступен один пункт «Без участка». Нормально ли это выглядит — к глазам.
- **`CREATE EXTENSION pg_trgm` требует прав суперпользователя.** Локально они
  есть, у прод-роли — вопрос открытый. Выяснить до `make prod-deploy`, иначе
  миграция `b6e4a9d31c05` упадёт на первой строке.
- **Старые `schedule_screen*.dart` и мёртвая `getAllTOGraphics`
  (`schedule_page.dart:281`)** — за ними вход в редактор ТО, отдельный заход.
- План этапа не отражает переделку: в нём всё ещё описано окно участков.

1. `make up`, войти админом: «Графики» → сразу лента всех объектов, фильтры
   пустые → клик по жёлтой клетке → карточка работы.
2. Главная → «Выполнение графика» → клик по строке участка: раздел
   переключился, пункт меню подсвечен, стоят пилюля участка и год выбранного
   месяца. Отдельно — строка «Без участка».
3. Тем же путём прорабом: лента сразу, чужих участков ни в ней, ни в
   выпадающих фильтрах.
