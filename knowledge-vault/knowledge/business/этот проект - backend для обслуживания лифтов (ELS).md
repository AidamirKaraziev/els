# Этот проект - backend для обслуживания лифтов (ELS)

## Что это
Backend «Единая лифтовая система»: REST API на FastAPI для сущностей вокруг обслуживания лифтов — организации, объекты, договоры, акты, наряды, справочники, пользователи и роли.

## Для чего эта заметка
Чтобы у Claude был “бизнес-контекст по умолчанию” при чтении vault, даже если задача чисто техническая.
