# PDF — генерация дефектной ведомости через ReportLab

## Решение
Для генерации PDF дефектного акта используем **ReportLab** (Python), формирование выполняется отдельным запросом API и сохраняет путь в поле `pdf_file`.

## Почему так
- Не требуется браузер/Headless Chrome.
- Хорошо контролируется верстка (таблица + сетка изображений), можно постепенно приближать к официальному шаблону.
- Поддерживает вложение изображений из файловой системы (`static/...`).

## Детали реализации
- Сервис: `src/services/defective_act_pdf.py`.
- Источник данных: таблицы `defective_acts` + `defective_act_photo` + связи (`planned_to -> object`, `status`, `responsible_user`, `created_by_user`).
- Верстка: A4 landscape, заголовок “ДЕФЕКТНАЯ ВЕДОМОСТЬ”, таблица 4 колонки, блок “Фотоматериалы” (3 фото в ряд), подписи.
- Шрифты/кириллица:
  - Локально можно использовать `static/fonts/NotoSans-Regular.ttf`.
  - В Docker добавлены системные шрифты (`fonts-dejavu-core`) для кириллицы без хранения TTF в репозитории.
