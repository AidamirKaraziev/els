# Пакетный менеджер - uv sync и фиксированный uv.lock

## Решение
Проект использует **uv** как менеджер окружения/зависимостей, с фиксированным lock-файлом `uv.lock`.

## Почему это важно
- В Dockerfile зависимости ставятся командой `uv sync --frozen --no-dev`, что ожидает корректный `uv.lock`.
- Для воспроизводимых окружений важно не “плыть” по версиям.
