# Lift App (ELS) — правила работы Claude Code

## Контекст проекта
- **Проект**: backend «Единая лифтовая система» (FastAPI REST API)
- **Стек**: FastAPI, SQLAlchemy 1.4, Alembic, PostgreSQL, JWT (python-jose), uv/uvicorn, Ruff
- **Точка входа**: `src/main.py`
- **API**: префикс `settings.API_V1_STR` (см. `src/config.py`), роутер `src/api/api_v1/api.py`

## Правила разработки в этом репозитории
- **Не коммить секреты**: `.env` и любые пароли/ключи не добавлять в git.
- **Соблюдать стиль**: формат и линт через Ruff (см. `pyproject.toml`).
- **Миграции**: изменения моделей сопровождаются Alembic миграциями (если проект это использует для окружения).
- **Проверка изменений**: после правок стараться запускать линт/тесты/миграции по месту (если доступно).

## Obsidian Knowledge Vault
**Хранилище знаний (внутри репозитория)**: `els-vault/`

### При старте сессии
1. Прочитай `els-vault/00-home/index.md`
2. Прочитай `els-vault/00-home/текущие приоритеты.md`
3. Если задача касается конкретного модуля/сущности — найди и прочитай заметку в `els-vault/knowledge/` или `els-vault/atlas/`.

### Правило совместимости (Windows-safe)
- В `els-vault/` нельзя использовать символы `< > : " / \ | ? *` в именах файлов.
- Нельзя заканчивать имя файла пробелом или точкой.
- Для проверки: `make vault-check`.

### При завершении (пользователь пишет: «сохрани сессию»)
1. Создай заметку в `els-vault/sessions/` с датой и кратким логом работы.
2. Обнови `els-vault/00-home/текущие приоритеты.md`.
3. Если принято решение — создай/обнови заметку в `els-vault/knowledge/decisions/`.
4. Если найден/починен баг — создай/обнови заметку в `els-vault/knowledge/debugging/`.
5. Обнови `els-vault/00-home/index.md`, если появились новые важные заметки.
