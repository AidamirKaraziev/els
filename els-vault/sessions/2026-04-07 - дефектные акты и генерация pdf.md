# 2026-04-07 — дефектные акты и генерация PDF

## Что сделали
- Доработали доменную сущность **дефектного акта**: `DefectiveAct` привязан к `planned_to_id`, добавлены поля `month`, `title`, `description`, `responsible_user_id`, `created_by_user_id`, `status_id`, `pdf_file`, timestamps.
- Добавили таблицу фотографий `DefectiveActPhoto` (много фото на 1 акт) и API для загрузки/просмотра/удаления записи.
- Добавили API для дефектных актов: создание, обновление (admin-only), смена статуса (admin-only), выборка по `planned_to_id` (с фильтром по месяцу).
- Реализовали генерацию PDF отдельным запросом: `POST /defective-act/{id}/pdf/`.
  - Генерация сделана через **ReportLab** (`reportlab`, `pillow`), с версткой “Дефектная ведомость” (таблица + фотоматериалы) по образцу.
  - Для кириллицы подключен шрифт `static/fonts/NotoSans-Regular.ttf` (локально) и добавлены системные шрифты в Docker (`fonts-dejavu-core`).
- Добавили миграцию Alembic на новые таблицы.

## Примечания
- `static/` в проекте игнорируется через `.gitignore`, поэтому шрифты в `static/fonts` не попадут в репозиторий — в контейнере используем системные шрифты.
