# Конфигурация - .env через BaseSettings и get_url из DB переменных

## Базовая идея
- Приложение читает переменные окружения из `.env` (python-dotenv) и настроек (pydantic `BaseSettings`).
- URL подключения к БД формируется из `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`, `DB_NAME` (см. `get_url()` в `src/config.py`).

## Важно
- `.env` **не коммитить**.
- В Docker Compose переменные пробрасываются в сервис `backend` и `postgres` из `.env`.
