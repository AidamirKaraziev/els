## Осталось по авторизации

**Данные, а не код — сделать до выката:**
- **Три механика (id 55, 56, 73) не назначены ни на один объект**, клиент
  id 62 привязан к компании «Мега» без объектов. После выката все четверо
  увидят пустые экраны. Найдено прогоном фильтров на копии боевой базы.
- **Проверить, у всех ли прорабов заполнен участок.** Прораб без участка не
  создаст объект — ответ `403` с кодом `136`.

**Решения заказчика:**

  только админ (раньше мог прораб), контактных лиц клиент не редактирует.
- **Подтвердить видимость списка людей.** Сотрудник видит коллег своих
  участков и себя. В матрице про это не сказано, решение принято по ходу:
  [[список людей режется по участкам, а не по назначениям]].

**Мелочи по коду:**
- **Убрать из `.env` мёртвые `SECRET_KEY_MODERATOR` и `SECRET`** — таких полей
  в `Settings` нет, их не читает никто.
- **Таблица `area_of_responsibility` живёт в базе, кода за ней нет.** Модель
  оставлена только потому, что её импортирует `alembic/env.py:42`: удаление
  увело бы таблицу с данными под снос при автогенерации. Решить, нужна ли она.

  фотографий — научить принимать список путей. Решать по итогам сессии фронта:
  [[файлы отдаются по короткоживущей ссылке, а не боевым токеном]].

  админского осталась проверка роли `[ADMIN]` с прежних времён. Работает

## Осталось по фронту и монорепо
- **Адаптивность экранов** (40–80 ч) — класс `Responsive` есть, но используется
  в 5 файлах на главной. Большие экраны свёрстаны под десктоп, а в 64 файлах
  логика завязана на hover, которого на тач-экране нет.
- **PWA-манифест** — теперь, когда HTTPS есть, service worker регистрируется
  и приложение можно ставить на домашний экран. Осталось заполнить
  `web/manifest.json`: имя, иконки, цвет; снять `portrait-primary`, иначе
  табличная админка на планшете заблокирована.
- **Почистить `pubspec.yaml`**: 12 неиспользуемых пакетов (`badges`,
  `gradient_borders`, `toggle_switch`, `prompt_dialog`, `auto_size_text`,
  `calendar_date_picker2`, `html`, `convert`, `equatable`, `bloc_concurrency`,
  `stream_transform`, `flutter_svg`) и дубль `location` с `geolocator`.
  Не зависит от решения по платформам.
- **`frontend/pubspec.lock` обновить локально** — в контейнере он не
  сохраняется и сейчас расходится с `pubspec.yaml`.
- **Если нативные остаются** — пересоздать `android/` шаблоном: Gradle 7.4 и
  AGP 7.1.2 не понимают Java 21, а разрешения объявлены внутри `<application>`,
  из-за чего Android их игнорирует и геолокация на телефоне не работала бы.
- Проверить на сервере, что деплой не завязан на старые пути: compose переехал
  в `infra/`, команда запуска теперь с `--project-directory .`.

  или выносом в объектное хранилище.

  выката `d5eeef9` работает и форма через запятую, можно переписать
