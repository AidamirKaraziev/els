## Решения
- [[одна кодовая база, но своя точка входа для мобильной сборки]]
- [[пакетный менеджер - uv sync и фиксированный uv.lock]]
- [[pdf - генерация дефектной ведомости через reportlab]]
- [[монорепозиторий - код в одном репо, но связь только через REST]]
- [[настройки фронта - dart-define, а не .env в рантайме]]
- [[фронт правится по макету, а не по коду подрядчика]]
- [[выборщик точки на карте - живой пакет вместо заброшенного]]
- [[справочник поломок - флаг counts_as_breakdown вместо списка id в коде]]
- [[тяжесть категории - порядок берётся из id, отдельного ранга нет]]
- [[статистика - показываем время реакции, а не время устранения]]
- [[выход из аккаунта живёт в профиле, а в профиль ведёт аватарка]]
- [[образы собирает CI, а сервер только скачивает]]
- [[режим nginx переключается переменной, а не правкой конфига]]
- [[отчёт в PDF собирает сервер одним кодом с экраном]]
- [[роли - enum в коде и матрица прав, а не RBAC в базе]]
- [[видимость данных - несколько участков на сотрудника, клиент по компании]]
- [[сессии - refresh-токены строками в базе, а не только JWT]]
- [[файлы отдаются по короткоживущей ссылке, а не боевым токеном]]
- [[список людей режется по участкам, а не по назначениям]]
- [[картинки грузятся с заголовком, а не по короткоживущей ссылке]]
- [[план ТО - заполненная ячейка месяца, а не отдельный признак]]
- [[выполнение считается по дате закрытия акта, а месяц берётся из плана]]
- [[просрочка - это незакрытое ТО, а не закрытое с опозданием]]
- [[просроченные ТО показываются на сегодня за два года, а не за месяц]]
- [[период отчёта режется по датам, а ТО — по плановому месяцу целиком]]
- [[экран отчётов собирается из приёмов соседних кадров, своего макета у него нет]]
- [[подсказки новичкам - значки и карточка, а не тур с подсветкой]]
- [[список работ механика - четыре раздела вместо кадра про ТО]]
- [[заявку ведут двое - исполнитель и механик объекта]]
- [[уведомления механика считает телефон, а не бэкенд]]
- [[фотография ждёт связи в очереди и сжимается на входе]]
- [[балл сотрудника считается по нормативам отрасли, а не относительно лучшего]]
- [[сложность работы берётся из тяжести категории и длины чек-листа]]
- [[рейтинг сотрудников закрыт отдельным правом, а не общей статистикой]]
- [[чек-лист хранится канонически, а наружу отдаётся в старой форме]]
- [[пауза по ТО - это «Принято» при начатой работе, а не новый статус]]
- [[механик завершает работу, а слово «акт» остаётся в базе]]
- [[строка списка - короткая пилюля и серый хвост]]
- [[счёт времени у аварии идёт от заведения заявки, а не от звонка]]
- [[текущие работы прораб видит по своим участкам, а не по всем]]
- [[карточка текущей работы у прораба всё-таки нужна]]
- [[незаполненное поле называется словами, а не прячется]]
