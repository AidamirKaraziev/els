# Фронт Вовы переехал в монорепо и запустился в docker

Начали с вопроса «познакомься с проектом и оцени объём работы по чужому
фронту», кончили тем, что вся система поднимается локально одной командой
`make up`, а веб-приложение открывается в браузере и показывает экран входа.
Восемь коммитов, `50689bb..9426010`, миграций Alembic нет, тестов на бэкенде
стало 11. Сборка веба в docker проходит, сборка APK — нет, но упирается не
в наш код.

Отдельно стоит помнить: оценка фронта по ходу сессии сдвинулась дважды.
До получения кода я называл 80–160 часов, после аудита снял эту цифру и дал
60–100 «как есть» либо 190–290 «с приведением в порядок», а шаг с поднятием
компиляции оказался дешевле нижней границы — ошибок в Dart-коде не было вовсе,
весь ремонт уложился в зависимости.

## Что собрали

- **Тесты ожили** (`50689bb`, `e49077c`) — тестовая БД поднимается контейнером
  из `infra/docker-compose.test.yml`, `db_session` снова откатывает
  транзакцию, появился тест на саму изоляцию фикстуры. Тесты локаций падали
  не из-за фикстуры, а из-за конфликта с городами из `create_initial_data`.
- **Раскладка монорепо** (`27f9bc5`) — 229 файлов переехали через `git mv`,
  история каждого цела. Корневой `Makefile` стал единой точкой входа,
  CI на GitHub Actions поднят.
- **Код фронта внутри репозитория** (`8151268`) — `git subtree add`, 7 коммитов
  `VladimirSV` теперь в нашей истории. Забирать доступ обратно не с чего.
- **Весь стек в docker** (`a6da745`) — nginx отдаёт веб-сборку и проксирует
  `/api/v1` на бэкенд, один origin на всё. Порт наружу один.
- **Адрес бэкенда больше не зашит** (`b4f1b60`) — 185 подстановок в 65 файлах
  заменены на `ApiConfig.base`, веб берёт origin страницы.
- **Выбор фото работает на всех платформах** (`68e6013`) — `image_picker`
  вместо web-only `ImagePickerWeb`.
- **Настройки через dart-define и gzip** (`9426010`) — `main.dart.js` по сети
  был 5.0 МБ, стал 1.3 МБ.

## Развилки, снятые с заказчиком

- **Раскладка `backend/` + `frontend/` + `infra/`** вместо «бэк в корне, фронт
  рядом». Заплатили разовой правкой путей и сменой команды деплоя.
  См. [[монорепозиторий - код в одном репо, но связь только через REST]].
- **Готовый живой пакет для выбора точки на карте** вместо своего виджета.
  См. [[выборщик точки на карте - живой пакет вместо заброшенного]].
- **Настройки фронта через dart-define, а не `.env`.**
  См. [[настройки фронта - dart-define, а не .env в рантайме]].
- **Одна кодовая база на веб, iOS и Android** — Flutter остаётся, вопрос
  «не переписать ли админку на веб-стек» снят заказчиком. Дублирование,
  которое убираем, — ролевое (`screns/` против `foreman/`), не платформенное.

## Открыто

- **Решение заказчика по мобильным приложениям.** Если веб-приложение вместо
  нативных — удаляем `frontend/android` и `frontend/ios` (59 файлов), и вместе
  с ними исчезает блокер с Gradle. Спросить надо про две вещи: нужны ли
  push-уведомления на iPhone (в вебе работают только для PWA, добавленного на
  домашний экран) и нужна ли работа без сети в машинных отделениях.
- **Если остаются нативные приложения** — `android/` придётся пересоздавать
  шаблоном: Gradle 7.4 и AGP 7.1.2 не понимают Java 21, а разрешения
  объявлены внутри `<application>` и потому Android их игнорирует. Нужны
  `applicationId` (сейчас шаблонный `com.example.els`) и имя приложения.
- **Адаптивность экранов** — класс `Responsive` есть, но используется в
  5 файлах на главной. Большие экраны свёрстаны под десктоп, а в 64 файлах
  логика завязана на hover, которого на тач-экране не бывает.
- **PWA — дефолтный шаблон**: в `web/manifest.json` имя «els» и описание
  «A new Flutter project.». Нужны имя, иконки, цвет; `portrait-primary` снять.
- **HTTPS обязателен** для геолокации и service worker — сейчас всё по HTTP.
- **12 неиспользуемых пакетов** в `pubspec.yaml` и дубль `location`
  с `geolocator`. Чистить можно независимо от решения по платформам.
- **`BACKEND_CORS_ORIGINS` заполнить в проде** — пока пусто, API открыт для
  любого домена, в лог пишется предупреждение.
- **`frontend/pubspec.lock` обновить локально** — в контейнере он не
  сохраняется, сейчас расходится с `pubspec.yaml`.
