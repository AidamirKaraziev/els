# pydantic 1.10 ломается на Python 3.12 - venv бэкенда закреплён на 3.11

## Симптом

При сборе тестов pytest падает на импорте:

```
TypeError: ForwardRef._evaluate() missing 1 required keyword-only argument: 'recursive_guard'
```

## Причина

В Python 3.12 изменилась подпись `typing.ForwardRef._evaluate`, а pydantic
1.10.10 (закреплён в `backend/pyproject.toml`) вызывает её по-старому.
`requires-python = ">=3.8"` разрешает любой интерпретатор, поэтому `uv sync`
на новой машине спокойно берёт 3.12 и окружение перестаёт работать.

Вылезло при переезде в моно-репо: старый venv в корне был на 3.11, новый
`backend/.venv` uv собрал на 3.12.

## Фикс

Файл `backend/.python-version` со значением `3.11`. uv читает его и берёт нужный
интерпретатор сам — ни на локальной машине, ни в CI гадать не приходится.

## Чего НЕ делали

Не поднимали pydantic до 1.10.13+ (где 3.12 поддержан) и не трогали
`requires-python`: это правка зависимостей боевого приложения, её место —
отдельная задача по обновлению стека, а не походу мимо. В образе, к слову,
до сих пор `python:3.8-slim`, то есть прод и локалка расходятся на две минорные
версии — это отдельный долг.
