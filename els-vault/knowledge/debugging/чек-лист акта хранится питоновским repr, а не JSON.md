# Чек-лист акта хранится питоновским repr, а не JSON

## Что выяснилось

`acts_fact.step_list_fact` — колонка `String`, и в схемах она объявлена как
`Optional[str]`. Ни бэкенд, ни фронт её содержимое **нигде не разбирают**:
поиск по `step_status` и `substep_name` во всём репозитории не даёт ни одного
попадания, кроме шаблона `src/steplist_tamplate.json`.

Формат нашёлся в закомментированном коде подрядчика,
`screns/schedule/schedule_page.dart`:

```dart
// String stringTest = listActualActsInObject[0]['step_list_fact']
//     .replaceAll("'", '"');
// selectedActualActsInObject = json.decode(stringTest);
```

Замена одинарных кавычек на двойные перед разбором означает одно: в базе
лежит **питоновский repr словаря**, а не JSON. `json.loads` на таком падает.

Справочника значений `step_status` не существует тоже — их пишет фронт, и
встречаются и строки, и булевы.

## Как обошли

`getters/reports.work_steps` пробует по очереди `json.loads`, затем
`ast.literal_eval`, и на любой неудаче возвращает пустой список. Значения
статуса сверяются с широким набором меток (`true`, `1`, `да`, `выполнено`),
всё прочее считается невыполненным.

Пустой список означает **«чек-лист не заполнен»**, а не «работ не было», и
экран с PDF обязаны писать это словами. Разница существенная: в отчёте
заказчику пустое место читается как «ничего не делали».

Три теста закрывают оба формата и мусор:
`test_checklist_is_parsed_from_python_repr`, `test_json_checklist_also_works`,
`test_unreadable_checklist_gives_empty_steps`.

## Урок

**Колонка типа `String` без единого читателя — это не «просто текст», а
неизвестный формат.** Прежде чем что-то из неё показывать, надо найти того,
кто в неё пишет. Здесь писателем оказался фронт, а единственным свидетелем
формата — закомментированная строка.

`ast.literal_eval` тут безопаснее `eval` и достаточен: в поле лежат только
литералы. Но полагаться на это как на долгосрочное решение нельзя — при
первой же правке экрана графиков формат может измениться снова, и заметить
это будет нечем, кроме пустых чек-листов в отчёте.

Если понадобится считать что-то по чек-листу (например, «выполнено N из M» в
статистике), поле надо сначала привести к JSON миграцией и закрепить схемой.

заполнять этот чек-лист с телефона, и на repr-формате это не построить.
