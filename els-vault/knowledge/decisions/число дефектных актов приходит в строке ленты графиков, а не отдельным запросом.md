# Число дефектных актов приходит в строке ленты графиков, а не отдельным запросом

Ручка `GET /schedules/rows` отдаёт в каждой строке поле `defects_count` —
сколько дефектных актов у объекта за год ленты. Считается коррелированным
подзапросом в `crud_schedules._defects_count`, рядом с остальными колонками
строки. Значок в строке (`DefectsBadge`) просто читает число из ответа.

Отклонённый вариант — значок сам ходит на сервер за счётом по каждому
объекту (ручка `count` на объект, как это делает `LiveDefectsBadge` в
карточке объекта подрядчика).

## Почему
- Страница ленты — полсотни строк. Полсотни запросов ради полсотни чисел
  при каждой прокрутке клали бы сервер зря, а значки мигали бы по очереди.
- Условия счёта те же, что у ленты актов объекта
  (`crud_defective_act.get_by_object_and_year`): год создания, только
  `kind == "internal"`. Клиентские акты порождены из внутренних и своего
  счёта не заслуживают. Иначе число в ленте и в карточке объекта разошлось
  бы, и заказчик спросил бы, какое из них правда.
- Область видимости в подзапросе не режется: объект строки человеку уже
  виден, а для видимого объекта `defective_act_scope_filter` пропускает
  все его акты.
- Старый контракт ручки жив: поле добавлено, ничего не убрано. Фронт, не
  знающий о `defects_count`, работает как раньше.

## Цена решения
- Год счёта жёстко равен году ленты (`period.date_from.year`). Показать
  «все дефекты за всё время» этим полем нельзя — нужен отдельный параметр.
- Тап по значку открывает список дефектов за тот же год, что и лента, и по
  возвращении строка перечитывается (`GET /schedules/rows?object_id=…`),
  чтобы число догнало заведённые в списке акты. Это лишний запрос на
  каждый возврат — принято, потому что он один, а не полсотни.

## Когда вернёмся
- Если в E02 (статистика, отчёты) понадобится тот же счёт по объектам за
  период — выносить подзапрос в общий helper, а не копировать.
- Если лента начнёт тормозить на больших участках — смотреть план запроса:
  коррелированный подзапрос на строку заменяется на `GROUP BY` по
  `object_id` в CTE.
