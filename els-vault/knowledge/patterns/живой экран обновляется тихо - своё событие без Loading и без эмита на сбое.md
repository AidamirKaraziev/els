# Живой экран обновляется тихо: своё событие без Loading и без эмита на сбое

Экран, который перечитывает себя по таймеру, не может ходить тем же событием,
что и первая загрузка: то гасит содержимое скелетом и стирает всё, что человек
развернул руками. Заводим второе событие — тихий перезапрос.

```dart
Future<void> _loadAct(
  Emitter<WorkDetailsState> emit, {
  bool silent = false,
}) async {
  final WorkDetails details;
  try {
    details = await _repository.fetchDetails(workId);
  } on WorkDetailsException catch (error) {
    if (silent) return;                       // на экране остаётся прежнее
    emit(WorkDetailsFailure(message: error.message));
    return;
  }
  ...
}
```

Событие `WorkDetailsRefreshed` вызывает тот же загрузчик с `silent: true`.
Отличий ровно три: не эмитится `Loading` перед запросом, сбой не эмитит
ничего, и части ответа, которые могли не доехать, берутся из текущего
состояния, а не подменяются пустыми.

## Почему так

- **Скелет раз в минуту** — это мигание экрана и схлопнутый чек-лист, который
  человек разворачивал руками. Состояние виджета переживает подмену данных
  (тип и позиция в дереве те же), а вот подмену на `Loading` — нет.
- **«Не удалось загрузить» на месте живых данных врёт сильнее, чем данные
  минутной давности.** Прораб не узнаёт из этой надписи ничего, а чек-лист
  сообщал хоть что-то. Следующим тактом экран догонит сервер сам.
- **Пустой ответ по части данных читается как факт.** Упавший запрос снимков
  вернул бы «снимков нет», а под молчаливым чек-листом ещё и подпись «механик
  ничего не оставил» — прямое враньё от одного дрогнувшего запроса. Поэтому на
  тихом такте снимки и телефон берутся из прежнего состояния.

## Что важно не забыть

- **Таймер живёт в виджете, а не в блоке**: остановить его надо вместе с
  экраном, а про экран знает виджет. `WidgetsBindingObserver` гасит такт на
  свёрнутом приложении и перечитывает сразу на `resumed`.
- **У конечного состояния такт останавливается.** Сданная работа обратно в
  работу не возвращается — спрашивать про неё каждую минуту незачем.
- **Тесты пишутся на такт, а не на данные**: поддельный репозиторий со
  счётчиком вызовов, `tester.pump(Duration(minutes: 1))`,
  `handleAppLifecycleStateChanged`, в конце снять дерево, чтобы таймер не
  пережил тест. Образец —
  `frontend/test/in_progress_works/work_card_live_test.dart`.

Приём уже стоит в двух местах: раздел «Сейчас в работе»
(`widgets/in_progress_works_live.dart`) и карточка работы
(`widgets/work_card_live.dart`). Такт у них общий — минута; расходиться им
нельзя, иначе прораб вернётся к списку и увидит другое.
