# Раздел фронта верстается на фикстуре через свою точку входа в lib/dev

Пока внешний вид раздела не утверждён, он смотрится не через вход и
оболочку подрядчика с живой базой, а отдельной точкой входа:

```dart
// frontend/lib/dev/schedules_preview.dart
void main() => runApp(const SchedulesPreviewApp());
// внутри — MaterialApp с ru-локалью и раздел на FixtureSchedulesRepository
```

Запуск: `flutter run -t lib/dev/schedules_preview.dart -d chrome`, либо
конфигурация в `.claude/launch.json` (по одной на раздел, порты 5599+).
Фикстура-репозиторий лежит в `lib/screns/<раздел>/repository/fixture_*`,
а не в `test/`: по ней собирается точка входа, и `test/` в сборку
`flutter run` не попадает. Для точек с суффиксом `_live` тот же экран
подключается к стенду `make up` через `--dart-define=API_ORIGIN`.

## Почему так
- Вход подрядчика требует логина, роли и живой базы; на вёрстку это не
  влияет, а времени ест много. Фикстура даёт нужные крайние случаи сразу:
  длинное название, ноль дефектов, двузначный счёт.
- Точка в `lib/dev/` в прод не попадает: сборка идёт с `lib/main.dart`, и
  ничто из приложения на `dev/` не ссылается. Это конвенция модуля, а не
  мусор — при чистке кода подрядчика их не трогаем.
- Одна фикстура кормит и превью, и `flutter test` — скриншоты для
  утверждения и тесты видят одни и те же данные.

## Что важно не забыть
- `flutter run -d web-server` из панели превью падает по DDS-вебсокету.
  Обход — статическая сборка: `flutter build web -t lib/dev/<точка>.dart
  -o build/preview-<раздел>` и `python3 -m http.server` из этой папки
  (конфигурация `schedules-preview-static`, порт 5611).
- Dev-точка не заменяет проверку на собранном стеке: пока экран не
  подключён к `lib/main.dart`, в `make up` его нет. Приёмка — только на
  `make up` под нужной ролью.
- Удаление мёртвого кода не меняет image id фронт-образа при кэшированной
  сборке — это не ошибка кэша, а признак, что код в `build/web` и не
  попадал. Пересобирать `--no-cache` стоит только чтобы в этом убедиться.

Применимо к любому новому экрану или разделу фронта: карточка объекта,
статистика в E02, окно задач.
