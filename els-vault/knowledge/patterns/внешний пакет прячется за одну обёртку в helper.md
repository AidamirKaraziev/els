# Внешний пакет прячется за одну обёртку в helper

Экраны не вызывают внешний пакет напрямую. Между ними и пакетом стоит один
файл в `lib/helper/`, отдающий результат в терминах нашего приложения.

```dart
// lib/helper/image_picking.dart — единственное место, знающее про image_picker
class PickedImage {
  final String? fileName;
  final Uint8List? data;
  const PickedImage({this.fileName, this.data});
}

Future<PickedImage?> pickImageFromGallery() async {
  final file = await ImagePicker().pickImage(source: ImageSource.gallery);
  if (file == null) return null;
  return PickedImage(fileName: file.name, data: await file.readAsBytes());
}
```

Так сделаны `helper/image_picking.dart` (выбор фото) и
`helper/my_map/address_picker.dart` (выбор точки на карте).

## Почему так

- Оба пакета, которые тут стояли раньше, пришлось менять: один заброшен,
  второй ломал мобильную сборку. Экраны при этом не менялись по существу —
  менялась обёртка.
- В этом коде виджет из внешнего пакета был вставлен **в три экрана копипастой**
  вместе с разбором ответа геокодера. Любая замена пакета означала три
  одинаковые правки и три возможности разойтись.
- Обёртка — место, где живут неочевидные детали: обязательный `userAgent` для
  Nominatim, чтение байтов вместо `XFile.path` (в вебе это blob-ссылка,
  по ней файл не загрузить), сборка адреса из улицы и номера дома.

## Что важно не забыть

- **Имена полей нейтрального типа стоит взять от того типа, который заменяем.**
  `PickedImage` получил `fileName` и `data` — как `MediaInfo` из выброшенного
  пакета, и оба nullable. Благодаря этому 54 обращения вида `imageFile.data!`
  в экранах остались нетронутыми: в диффе оказались только тип и вызов.
  Красивее было бы `bytes` и `name`, но это 54 лишние правки в чужом коде.
- Обёртка должна отдавать **наш** тип, а не тип пакета. Иначе пакет всё равно
  протекает в экраны через тип возвращаемого значения, и смысл теряется.
- Импортировать обёртку через `package:els/...`, а не относительным путём:
  в этом коде файлы лежат на разной глубине, и относительные пути я в этой
  сессии ломал трижды.

## Где ещё применимо

Кандидаты в этом проекте: `dio`/`http` (сейчас запросы разбросаны по 65 файлам
без общего клиента), `geolocator` вместе с дублирующим его `location`,
`syncfusion_flutter_datepicker`. Каждый — внешний пакет, вызываемый из экранов
напрямую.
