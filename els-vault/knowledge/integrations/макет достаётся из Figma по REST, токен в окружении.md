# Макет достаётся из Figma по REST, токен в окружении

Кадры макета забираются из Figma REST API обычным `curl`. Токен живёт
**только в окружении разработчика**, в репозиторий и в этот vault не
попадает.

Файл макета «КПЭК»: ключ `bsgJW2RZLQlZbYUq3peqbD`. Главная — узел `1:60`
(в адресе браузера он выглядит как `node-id=1-60`, дефис меняется на
двоеточие).

```bash
export FIGMA_TOKEN='...'   # Figma → Settings → Security → personal token

# отрендеренный кадр картинкой: отдаёт ссылку на PNG, живёт ~30 дней
curl -s -H "X-Figma-Token: $FIGMA_TOKEN" \
  "https://api.figma.com/v1/images/bsgJW2RZLQlZbYUq3peqbD?ids=1:60&format=png&scale=2"

# разбор узла: точные цвета, размеры, отступы, тексты
curl -s -H "X-Figma-Token: $FIGMA_TOKEN" \
  "https://api.figma.com/v1/files/bsgJW2RZLQlZbYUq3peqbD/nodes?ids=1:60"
```

Картинки хватает, чтобы увидеть общий вид и снять приёмы оформления. JSON
нужен, когда важны точные значения — цвет в hex, радиус скругления, кегль.

## Почему так, а не MCP

Официальный **Figma Dev Mode MCP** рассматривали и отклонили:

- требует десктопного приложения Figma и платного тарифа с местом
  Dev или Full;
- его главная ценность — генерация кода из выделения — целится в
  React и HTML, для Flutter почти бесполезна;
- палитра у нас всё равно своя, в `frontend/lib/helper/class_colors.dart`,
  и переменные дизайн-системы пришлось бы отображать на неё руками.

REST покрывает всё, что реально нужно, работает на бесплатном тарифе и не
требует ничего, кроме токена.

## Что важно не забыть

- **Токен — секрет.** Не вставлять его в переписку и не коммитить: один раз
  он уже был прислан в чат и его пришлось отзывать. Хранить в менеджере
  паролей, в шелл давать через `export`.
- Ссылка на PNG из `/v1/images` временная. Нужен постоянный файл — скачать
  сразу, но **не в репозиторий**: макет тяжёлый и меняется.
- Скоупа `File content: read` достаточно, права на запись не нужны.
