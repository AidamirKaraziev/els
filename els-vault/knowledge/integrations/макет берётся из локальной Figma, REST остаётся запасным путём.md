# Макет берётся из локальной Figma, REST остаётся запасным путём

Решение от 27 августа 2026: макет живёт в **Figma Desktop на машине
разработчика** и отдаётся её локальным Dev Mode MCP-сервером. Кадр читается
напрямую из выделения, без токена и без обращения к api.figma.com.

Прежний путь — REST-запросы с `X-Figma-Token` — не удаляется, но становится
запасным: он нужен, когда Figma не запущена или когда требуется кадр из файла,
которого нет в локальной сессии.

## Почему поменяли

- **Токен — постоянный риск.** Он уже был прислан в переписку и один раз
  засветился в выводе команды. Локальный MCP не требует секрета вовсе.
- Обращения по REST уходят наружу; локальный сервер работает без сети.
- Отпадает ручной перевод `node-id=1-60` → `1:60` и возня со ссылками на PNG,
  которые живут тридцать дней.

Прежний довод против MCP («требует десктопа и платного места Dev/Full»)
перестал мешать: десктоп и так стоит, а кадры смотрит человек с доступом.

## Что важно не забыть

- **Старый токен отозвать.** Пока он жив, он остаётся утечкой независимо от
  того, пользуемся мы им или нет.
- Кадры **не кладём в репозиторий**: макет тяжёлый и меняется.
- Палитра всё равно своя — `frontend/lib/helper/class_colors.dart`. Переменные
  дизайн-системы отображаем на неё руками, генерацию кода из MCP не берём:
  она целится в React и HTML, для Flutter бесполезна.
